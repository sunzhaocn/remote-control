# 试升稳定性复查（0.3.24）

本版针对画质反复跳动和恢复受阻的风险修复。继续优先流畅与低延迟；输入和视频内容本身不触发固定低清，30fps目标、正常90%尺寸及路径预算上限保持。

## 已复现并修复

1. 试升失败只约束有界试验，普通码率、网络分辨率和设备分辨率恢复可能绕过冷却。现三条恢复路径共用限制；发生失败后，本会话的后续提质走接收端验证的小步试验，紧急降档不受限制。
2. 帧节奏资格或带宽余量来回变化时，等待计时被反复清零，可能长期没有恢复机会。现在保留等待时间，条件重新具备时继续，不因资格波动永久重等。
3. 累计解码/显示计数包含先前积累，停滞后仍可能被误认为成功；好、坏尺寸交错的反馈也能累积通过。持续视频现在从参数应用后的新反馈建立基线，连续三个采样间隔均须有目标尺寸和足够新解码/显示提交进度，验证跨度至少2秒。坏尺寸、无进度、非递增采样时间或超过2秒的反馈间隔打断连续证据；重复反馈不能确认。
4. 普通逐档恢复也可能遇到非线性的编码/GPU负载，或试升刚通过后才暴露压力。现在保存提升前的安全配置，确认后8秒内出现压力会撤回；已有更强的紧急保护仍保留。普通自动提质同样有此检查。路径/尺寸/会话切换清除旧检查点。
5. 很低帧率视频或幻灯片的长帧间隔可能反复触发原屏文字精修。生产帧在超过1秒的静止判定后恢复时，原屏文字试验再等待5秒；周期帧会续延等待，真正暂停后仍能恢复文字精修。正常持续视频的原屏文字策略不受这个等待影响。

新增5个复现测试在修改前全部失败，见 `../artifacts/recovery-stability-reproduction.log`；完整应用回归涵盖修复后的行为与其他原有功能。

## 防抖与恢复边界

- 持续画面的单次试验最多5秒，覆盖新反馈建立基线和连续进度验证；静止试验仍最多2.5秒。参数重试不延长总期限，期间出现真实压力立即撤回。
- 首次试验边长最多增加12%、预算最多增加10%；一次失败后缩为6%/5%，两次及以后缩为3%/5%。试验仍有路径预算上限。更小步幅会使恢复较慢，用来减少重复碰撞负载边界。
- 连续失败按10、20、40、60秒退避，最长60秒；不因一分钟统计窗口滑过就突然恢复频繁重试。一分钟最多3个失败试验，后续仍允许重试，不永久封禁恢复。成功后有8秒提质间隔，静止试验另受原有节奏约束。
- 静止补帧仍有次数上限；持续高帧率视频使用自然到达的帧，不因为验证延长而无限补帧。原屏文字仍需编码精修或原有受限回退证据。
- 调试信息继续显示当前阻碍、上次回退原因和剩余等待秒数，包含“已撤回刚确认的试升”。

缺少接收反馈、持续排队或处理成本持续超标时，程序无法安全保证高清。此时仍显示原因、有限重试；不会以无条件提质换取积压。测试证明逻辑可以在压力和数据缺口解除后重新恢复，不代表所有手机或视频绝无可见画质变化。
