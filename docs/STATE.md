## 已知限制和阻塞

- 未修改的 WebRTC Android 预编译 AAR 没有公开入口把 `AudioPlaybackCaptureConfiguration` 注入其 `AudioRecord`；阶段 5 将维护最小源码补丁，但构建须另行授权。
- Android 14+ 的单应用共享可能由系统/厂商提供或覆盖应用的整屏偏好，应用必须识别捕获范围。
- 长期待机前台服务暂定 `connectedDevice` 类型；厂商后台策略和应用商店审核需要后续验证。
- 当前 Windows 环境未发现 JDK、Android SDK 或 Android Studio，阶段 1 尚未通过构建验证。
- 阶段 1 的待机服务不含信令，因此只显示服务运行状态，不代表设备在线可连接。
