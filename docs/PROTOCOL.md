# SimpleRC 协议基线

所有信令和控制消息包含协议版本、会话 ID、单调序号与发送时间。接收端限制消息 64 KiB，校验会话归属、序号递增、时间窗口、类型白名单和字段范围。旧会话、重放、过期、未知类型和越界输入直接拒绝，不进入重试队列。

控制 DataChannel 分两类：点击、长按、导航、确认和停止使用可靠有序通道；高频滑动点使用有序、有限寿命通道，并以完整手势为事务。断线或几何版本变化时丢弃未完成手势，恢复后不补发。

坐标只传归一化内容坐标和几何版本，不发送控制端原始像素。DataChannel 消息不是操作成功；被控端必须返回无障碍手势或全局操作的接受及完成/取消结果。
