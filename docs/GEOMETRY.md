# 几何与输入规则

控制端以实际视频内容矩形为输入边界。矩形已经包含 Compose 布局、WindowInsets 和宽高比留边的结果；触点先扣除矩形偏移，再按内容尺寸归一化，并逆向处理旋转。起点在留边时整段忽略，路径任一点越界时整段取消，绝不夹到边缘。

被控端使用同一几何版本对应的实际捕获区域映射到无障碍屏幕坐标。编码分辨率不参与映射，因此降画质不会改变触控位置。状态栏、导航栏、刘海和键盘只在实际改变捕获区域时反映到几何数据，不重复扣除固定高度。

方向或捕获范围改变时先递增几何版本并暂停触控；控制端完成新画面与内容矩形同步后恢复。旧版本命令一律拒绝。Activity 方向请求可能被多窗口或大屏系统忽略，此时仍以内容矩形保证比例和坐标。

输入框继续使用真实手势点击。阶段 4 不启用窗口内容读取，不调用本地 `showSoftInput` 冒充远端键盘；远端键盘只有在实际共享画面中出现后才可被点击。
