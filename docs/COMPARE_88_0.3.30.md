# 临时88%固定分辨率对照版

按“提升8%”在上一80%版上增加8个百分点实现：原屏宽、高各保留88%，约为原像素数77.44%，比80%版多约21%像素。该百分比指分辨率，不代表主观画质分数或码率比例。受浮点取整及编码偶数尺寸要求，1080×2400输出约950×2110。

延续80%版策略：滑动、按键、静止和视频均固定同一分辨率，不随操作或旧资源保护档进一步缩小。码率自适应、网络拥塞控制、队列保护、30fps目标和VSync保留。静止补帧不切回90%或原生分辨率。

这是独立构建`compare88`，包名`com.simplerc.app.compare88`，版本`0.3.30-compare88`，应用名“SimpleRC 88% 对照”。可与80%对照版和原版并排安装；两份已交付旧APK保留不变。正式默认配置仍为原0.3.30。

两端安装`../artifacts/SimpleRC-0.3.30-compare88.apk`，打开“SimpleRC 88% 对照”，为新应用重新授权，选择“新策略”并用新生成的ID连接。测试前断开旧版连接、停止旧版待机，只保持一组连接。在相同页面、视频、网络和音频设置下比较。

诊断前缀应为“88%固定对照：操作/静止/视频统一分辨率”。旧兼容策略不走这条固定分辨率管线，因此两端都需选择新策略。

构建：在android目录运行`./gradlew :app:testDebugUnitTest :app:testCompare80UnitTest :app:testCompare88UnitTest :app:assembleCompare88 :app:lintCompare88 :app:lintDebug --no-daemon`。核验`python -X utf8 artifacts/verify-compare88.py`，结果见`../artifacts/BUILD_0.3.30-compare88.json`。146项输入在构建前冻结，包括三个构建配置及所有源码/测试。

新增测试覆盖三种状态与保护档的固定88%输出、高分屏、静止精修、实际采集Buffer和独立构建开关，并回归普通版及80%版。签名、权限、三个前台服务类型及四个ABI原生库核验包含在交付检查中。未安装或测试用户手机，未双机实测流畅度、延迟和画质，未部署后端。
