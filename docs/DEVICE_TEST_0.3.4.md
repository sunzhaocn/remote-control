## 工具干扰与诊断边界

活动被控端的 uiautomator dump 会临时抑制无障碍，前两次共享被正式安全逻辑终止。改为只读取控制端结构、被控端专属日志和应用内截图后正常。依据 [Android UiAutomation](https://developer.android.com/reference/android/app/UiAutomation#FLAG_DONT_SUPPRESS_ACCESSIBILITY_SERVICES)，不把这两次作为自然后台被杀。诊断中一条系统帮助命令没有提供帮助而输出系统状态，另一条日志筛选范围过大；后续使用包名/进程限定，不保存该类原始输出，也不在报告引用无关内容。
