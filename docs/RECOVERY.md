# 重连状态机

`disconnected` 先短暂等待；仅信令断开则保持仍工作的媒体/控制并单独恢复信令；ICE failed 执行有限次数 ICE Restart，仍失败才重建 PeerConnection；媒体停滞直接进入重建评估。所有步骤共享 120 秒宽限期和有限指数退避加抖动。

重连期间拒绝控制并丢弃积压输入。恢复传输后先同步画面、方向、几何版本和静音意图，完成后才开放操作。租约继续由原会话续约，不能重新走公开凭据让其他控制者抢占。

用户停止、MediaProjection `onStop`、锁屏导致授权终止或进程死亡均为终止态，不自动重新取得授权。超过宽限期撤销恢复令牌并按归属释放租约。
