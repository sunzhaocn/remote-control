# 0.3.29 静止文字清晰档

本次按用户“双方都没操作时提升画质、看清字体”的反馈，增加独立静止清晰档。交互及持续视频仍使用0.3.28的实测带宽/设备保护和精确纹理缩放。

## 静止画质提升

- 画面真实停帧至少300ms、无有效交互提示后，继续稳定约1秒，才尝试文字清晰档。仅无触摸但视频还在出帧，不满足此条件。
- 清晰档尝试原屏尺寸，长边上限从2400提高到3200；1440×3200以内可使用原屏细节。普通交互/视频长边上限仍为2400、正常每边约90%。
- 文字精修预算至少尝试8Mbps，仍受当前传输路径总预算上限约束；既有连续档预算高于8Mbps时不强行降低。预算是编码上限，不承诺或强制以8Mbps发送，带宽估计、拥塞控制和真实压力回退保留。
- 静止快照可在连续视频安全档仍被保护时独立试验，避免先等待多轮视频恢复。确认后的尺寸和预算只用于静止快照，不写入连续档；用户操作或真实画面恢复时，立即还原连续档原有分辨率、码率及保护状态。
- 精修最少补12次输入，给关键帧后细节继续收敛；每次间隔至少150ms，最多24次。若编码精修未完成，也不能无限造帧。文字验证最长6秒，仍需新接收尺寸/解码和显示进度确认；发送排队、设备耗时超标或缺少确认会撤回并退避。
- 源画面恢复时，补帧器独立检查并停止文字补帧，即使策略线程已先清除了静止标记也不会遗漏。静止纹理重放不计作新屏幕活动。

## 范围与验证

返回保护、无障碍、远端导航和亮屏生命周期没有修改；无新增权限、无服务端部署，AAR与原生库未重建。

新增回归覆盖保护档下临时清晰、确认后恢复原视频预算/像素、真实压力阻止清晰试验、路径预算上限、最少12/最多24次补帧、视频恢复取消补帧及普通视频恢复突发不受干扰。构建和校验结果见 `../artifacts/BUILD_0.3.29.json`、`BUILDING.md`。

两端均覆盖安装0.3.29，选择新策略并断开重连。未安装或操作用户的OPPO Android11/vivo Android16；自动测试不等于实际字体、画面质量或物理延迟实测。若静止内容仍有持续动画或定时刷新，或真实链路/设备仍有压力，清晰试验可能延后或撤回；诊断继续显示原因和目标/编码/解码尺寸。
