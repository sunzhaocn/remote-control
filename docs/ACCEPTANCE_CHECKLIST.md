## 凭据、配对和租约

- [ ] 首装创建设备身份；清数据后旧固定 ID 不可直接抢回。
- [ ] 固定 ID 冲突原子拒绝；同设备重连不误判；每设备最多一个固定 ID。
- [ ] 自定义凭据重启保持；随机凭据 300 秒原子刷新，旧组合立即失效。
- [ ] 控制端角色不生成被控凭据；旋转、权限往返不刷新。
- [ ] 未知 ID、错码、未启用、已占用使用同一提示和相近耗时；网络错误单独显示。
- [ ] 两个控制端竞争时仅一个取得租约；确认、握手、连接和 15 秒重连期内第二人不能抢占。
- [ ] 30 秒确认超时、20 秒握手超时正确释放；主动停止后旧恢复令牌无效。

## 采集、控制、方向和坐标

- [ ] 每次新共享都出现系统授权；授权 Intent 不复用；锁屏/系统停止后必须重新授权。
- [ ] Android 14+ 整屏与单应用选择可区分，单应用时不冒充全屏控制。
- [ ] 连续横竖屏不重新配对、不重复授权；多窗口忽略方向时比例和触控仍正确。
- [ ] 不同分辨率、宽高比、密度、显示缩放、刘海、三键/手势导航组合画面不拉伸。
- [ ] 四角、边缘、中央和小按钮点击准确；留边点击不发送。
- [ ] 长按和滑动完整路径准确；滑动任一点越出内容区时整段取消并提示。
- [ ] 降低编码分辨率后坐标不漂移；旧几何版本事件拒绝。
- [ ] 返回、桌面、最近任务检查系统返回值；重连时禁用，断开后隐藏。

## 输入法

- [ ] 普通输入框、网页和聊天输入框通过真实远程点击获得文本焦点。
- [ ] 远端中文键盘、候选栏和横屏键盘实际出现在共享画面并可准确点击。
- [ ] 控制端本地键盘与远端键盘分别出现时不互相混淆；WindowInsets 不被当成远端键盘高度。
- [ ] 密码框、安全键盘和受保护内容限制如实提示，不读取或记录内容。

## 网络、重连和 TURN

- [ ] LAN、公网 P2P、TURN/UDP、TURN/TCP/TLS 的路径显示来自选中候选对。
- [ ] host candidate 不会被一律显示为 LAN；TURN 密钥不在 APK。
- [ ] 仅信令断开时媒体继续；恢复信令不重新配对。
- [ ] 断网3/10秒可尝试恢复，超过15秒（含30秒）结束旧会话；Wi-Fi/移动网络切换可分级恢复；不补发旧输入。
- [ ] ICE restart 后可在直连与中继间切换；15 秒超时明确结束。
- [ ] projection 停止、权限撤销、锁屏或本机停止后不自动接管。

## 内部音频

- [ ] 被控端未允许音频或拒绝 RECORD_AUDIO 时，视频与控制仍可用并显示真实音频状态。
- [ ] 静音后控制端立即无声；收到 ACK 后显示“内部音频已停止发送”，并用 WebRTC outbound-rtp 统计确认 bytesSent 不再增长。
- [ ] 恢复声音后重新收到内部音频，不重新弹屏幕采集授权。
- [ ] 补丁版只采集允许捕获的媒体/游戏声音，不读取麦克风，不自动回退。
- [ ] 音频权限拒绝、远端禁止分享或不可捕获音源不影响视频和控制。
- [ ] 静音立即停播清缓存；确认前显示待确认；确认后 audio outbound RTP `bytesSent/packetsSent` 停止增长。
- [ ] 恢复声音不重启屏幕/配对且不回放旧缓存；音画同步可接受。
- [ ] PeerConnection 重建和网络切换保持静音，不短暂漏音。

## 实测反馈 A–C 复测

- [ ] 保存合法自定义 ID/验证码后等待超过 5 分钟，凭据保持不变且不出现随机 ID。
- [ ] 杀死进程后重新打开：模式和自定义值保留，但被控仍需手动启用；启用后只发布自定义凭据。
